# TechStore 2025

Tienda/dashboard de tecnología hecho en React 19 + TypeScript, con visualización de inventario (Recharts) y un asistente de IA (Gemini) que analiza el catálogo y sugiere mejoras de stock y estrategia. Consume una API REST propia desplegada en Render.

## Correr en local
1. `npm install`
2. Configurar `GEMINI_API_KEY` en `.env.local`
3. `npm run dev`
